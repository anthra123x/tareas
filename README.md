# Lista de Tareas

Aplicación web moderna y responsiva para la gestión eficiente de actividades y tareas diarias.

## Características

- Interfaz estilizada con diseño responsive (desktop y móvil).
- Filtrado por estado: Todas, Pendientes y Completadas.
- Persistencia local automática (`localStorage`).
- Servidor de desarrollo ultrarrápido impulsado por [Vite](https://vitejs.dev/).

## Instalación y Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el entorno de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
